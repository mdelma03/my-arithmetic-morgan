Bienvenue dans la documentation de my-arithmetic-morgan
=======================================================

**my-arithmetic-morgan** est une bibliothèque Python légère fournissant des
outils d'arithmétique élémentaire, dont le calcul du plus grand commun
diviseur (PGCD).

Installation
------------

.. code-block:: bash

   pip install my-arithmetic-morgan
